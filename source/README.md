# 研途搭子 (Study Companion)

AI 考研复习智能体 —— 上传复习资料，AI 自动出题、批改、诊断薄弱点。

**Team AAA**：林锶堉 · 吴圣林 · 黄添铨 · 何星宇

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动
python app.py

# 3. 浏览器打开
# http://127.0.0.1:5000
```

无需 API Key 即可运行（内置示例题库）。后续接入 Kimi / 文心一言 API 后可实现真实 AI 出题。

## 功能

- 资料上传与管理
- AI 自动出题（选择题 / 简答题）
- 在线答题与自动批改
- 考点分析与参考答案展示
- 学习数据统计

## 技术栈

- 后端：Python Flask + SQLite
- 前端：HTML / CSS / 原生 JS
- AI：Kimi / 文心一言 API（预留接口）
